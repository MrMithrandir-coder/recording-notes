# 数理与计算机术语、符号标准

本文件供 Codex 整理笔记时使用。`asr-terms.txt` 用于帮助 Whisper 识别，
`custom-terms.txt` 用于每门课或每个课题组的专有词。

## 总体规则

1. 首次出现时优先使用“规范中文（标准英文，缩写）”。
2. 后续使用该领域最常见的简写，但保持全文一致。
3. API、CPU、GPU、CUDA、QAOA、VQE 等缩写保持大写。
4. Python 包、函数、变量和命令使用反引号并保持大小写，例如
   `NumPy`、`torch.nn.Module`、`git rebase`。
5. 变量使用 LaTeX：标量 `$x$`，向量 `$\boldsymbol{x}$`，矩阵 `$A$`，
   算符 `\hat{H}`。若讲者或材料有自己的约定，以材料为准。
6. 数值和单位之间留空格，例如 `10 nm`、`3.2 GHz`、`25 °C`；无量纲量
   明确说明“无量纲”。
7. 对音近但无法确认的术语，不直接替换；列出候选和时间戳。
8. 逐词置信度只用于确定回听优先级。即使置信度较高，公式、专名、数值、
   单位和代码标识符仍须与课件、论文、代码或音频交叉核验。

## 常用规范写法

| 领域 | 规范中文 | 英文/缩写 | 易混或说明 |
|---|---|---|---|
| 线性代数 | 本征值、本征矢 | eigenvalue, eigenvector | 不统一替换为“特征”体系，除非课程采用该教材译法 |
| 量子 | 厄米算符 | Hermitian operator | 不写“埃尔米特”除非逐字引用 |
| 量子 | 幺正算符 | unitary operator | “幺正”不是“一正” |
| 量子 | 密度矩阵 | density matrix | 同义“密度算符”按上下文保留 |
| 量子 | 量子信道 | quantum channel | 与经典通信信道区分 |
| 量子 | 克劳斯算符 | Kraus operator | 保持 Kraus 拼写 |
| 数学 | 傅里叶变换 | Fourier transform | Fourier 首字母大写 |
| 数学 | 拉普拉斯变换 | Laplace transform | 与拉普拉斯算子区分 |
| 数学 | 欧拉-拉格朗日方程 | Euler-Lagrange equation | 使用连字符 |
| 概率 | 高斯分布 | Gaussian distribution | 与正态分布可视语境互用 |
| 统计 | 最大似然估计 | maximum likelihood estimation, MLE | “似然”不是“似然率” |
| 算法 | 动态规划 | dynamic programming, DP | 不误写为动态编程 |
| 系统 | 进程、线程 | process, thread | 二者不可互换 |
| 系统 | 并发、并行 | concurrency, parallelism | 二者不可互换 |
| 网络 | 传输控制协议 | TCP | 与 UDP 分开 |
| 软件 | 应用程序编程接口 | API | 通常直接写 API 即可 |
| 机器学习 | 梯度下降 | gradient descent | 与反向传播区分 |
| 机器学习 | 损失函数 | loss function | 不随意替换为代价函数 |
| 机器学习 | 交叉熵 | cross entropy | 公式必须说明离散/连续形式 |
| 机器学习 | 词元 | token | 若课程习惯“令牌”，首次注明对应关系 |
| 大模型 | 检索增强生成 | retrieval-augmented generation, RAG | 保持 RAG 大写 |

## 公式转写标准

- “x 下标 i”：在上下文明确时写作 `$x_i$`。
- “x 的平方”：在上下文明确时写作 `$x^2$`。
- “偏 x”：需区分偏导 `\partial/\partial x` 与参数或下标，无法确定就标记。
- “nabla”：根据语境写作 `\nabla`，并区分梯度、散度和旋度。
- “H”：量子语境可能是哈密顿量、Hadamard 门或希尔伯特空间；必须由上下文
  或材料确认。
- “rho”：通常写作 `$\rho$`，但不得仅凭发音断定它是密度矩阵。
- “psi/phi”：使用 `$\psi$`、`$\phi$`，并以材料中的大小写和下标为准。
- “大 O”：写作 `$O(\cdot)$` 或 `$\mathcal{O}(\cdot)$`，遵循课程材料。
- 期望使用 `$\mathbb{E}[X]$`，概率使用 `$\Pr(A)$` 或 `$P(A)$`，以材料为准。
- 代码复杂度、矩阵维度、样本量、单位和误差条必须逐项核查。

## 每门课/课题组应补充的内容

- 教师、报告人和实验室成员姓名及英文拼写。
- 课程名、课题名、项目代号和设备型号。
- 教材、论文作者、算法和数据集名称。
- 常用希腊字母、变量、算符、上下标和单位约定。
- 仓库、包、模块、类、函数、命令和配置字段的精确写法。
- 本领域采用但与本表不同的中文译法。
